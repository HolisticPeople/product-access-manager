# v2.15.1 - Product Access Contract Release

Product Access Manager v2.15.1 adds the typed public product-access contract for native product-page consumers.

## Changes

- Added `pam_get_product_access_contract()` with explicit `allow`, `deny`, and `unknown` states.
- Added `pam_compose_product_access_and_stock_state()` to document access, stock, Woo purchasability, and checkout precedence without moving ownership from WooCommerce, HP-Inventory, or HP-Checkout.
- Corrected Woo visibility, variation visibility, and purchasability gates so `deny` blocks consistently while `allow` and `unknown` preserve downstream Woo/Inventory/Checkout truth.
- Added focused PHP contract tests, including a version-consistency assertion for plugin header `Version` and `PAM_VERSION`.

## Boundaries

- No HP-Inventory edits.
- No HP-Checkout edits.
- No HP-Zen implementation.
- No staging or production mutation.
- No deploy.
